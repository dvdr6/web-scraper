Core MVP Features

BFS Crawler

Breadth-First Search logic explores pages level by level, ensuring a consistent crawl depth.

Asset Rewriting

Automatically converts all absolute links to local relative paths so the site works perfectly offline.

ZIP Export

Optional flag to package the entire downloaded site into a single compressed archive.

Terminal

# Start crawling with default settings (depth 3)

$ python scraper.py https://example.com

# Custom depth and output directory

$ python scraper.py https://example.com --depth 5 --output my_offline_site

# Export everything to a ZIP file

$ python scraper.py https://example.com --zip

Smart Directory Mapping

The scraper replicates the server-side directory structure locally. It intelligently identifies HTML pages, assets, and media, placing them in their respective folders while maintaining semantic integrity.

  • Preserves original file extensions
  • Handles root-relative and sub-folder links
  • Injects proper index.html for directory paths
